# Canal Libre — lecteur IPTV Android

Application Android (téléphone, tablette, Android TV) pour lire des playlists IPTV M3U/M3U8 et des flux HLS.

- Chargement d'une playlist par URL ou depuis un fichier
- Catégories, recherche, favoris, reprise de la dernière chaîne
- Lecture plein écran, flux HTTP et HTTPS, sans blocage CORS

L'APK est compilé automatiquement par GitHub Actions à chaque push sur la branche `canal-libre-android` et publié dans les **Releases** du dépôt.
